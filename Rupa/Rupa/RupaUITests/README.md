# Retired foreground UI automation

Deprecated historical reference, not a build target or executable test suite.
The Xcode UI-testing target and scheme reference have been removed. These files
are retained to preserve existing uncommitted user edits and the original
scenario assertions; no runner discovers them. Do not reattach this directory
to a test target. Their final disposition is archival retention, not migration
back to screen automation.

Run `bash RupaKit/scripts/test-ui-contracts.sh` from the repository root.
Replacement coverage and manual acceptance are owned by
[the UI test review](../../../RupaKit/Tests/UI_TEST_REVIEW.md).
